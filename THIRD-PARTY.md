# Third-party material in this mod

## Outfit

- **Where** `versions/fabric-26.3/src/main/resources/assets/hyades/font/outfit.ttf` (in every version's jar)
- **Upstream** <https://github.com/Outfitio/Outfit-Fonts> — Copyright 2021 The Outfit Project Authors
- **License** SIL Open Font License 1.1, in full beside the font as `OFL.txt`
- **Added** 2026-11-13 — the typeface of hyadesmc.net, so the HUD is set in the same hand
- **Changes** the Latin subset the website ships, fixed to the weight 500 (Medium) out of the variable font,
  because the game's font loader takes one weight per file. Letters it lacks are drawn in the game's own font.
